# Pre-Entrega Automatización QA

##  Propósito
Proyecto de pre-entrega del curso de Automatización QA.  
Automatización de flujos básicos en [saucedemo.com](https://www.saucedemo.com) usando Selenium WebDriver y Pytest.

## Tecnologías
- Python 3.x  
- Selenium WebDriver  
- Pytest  
- Git & GitHub  

##  Estructura
- `tests/` → Casos de prueba principales  
- `utils/` → Funciones auxiliares  
- `reports/` → Reportes HTML y capturas  
- `README.md` → Documentación del proyecto
